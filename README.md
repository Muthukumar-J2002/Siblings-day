# EJ Papa Birthday Website

A creative one-page birthday website for EJ Papa that mixes Tamil Bible-inspired blessing words, English birthday wishes, family fun, John Jebaraj song dedications, confetti, a random wish generator, and a local memory wall.

## Features

- Responsive birthday landing page with Tamil and English copy.
- Bible-inspired Tamil blessing cards with verse references.
- John Jebaraj worship-song dedication corner for birthday celebration ideas.
- Creative Tamil Bible verse party card with a funny Papa blessing.
- Filterable blessing cards for Tamil, Bible, fun, or all mixed wishes.
- Interactive birthday confetti and random blessing word picker.
- Creative Tamil-English birthday wish generator with worship, cake, and family-fun lines.
- Memory wall form saved with browser `localStorage` for demo notes.
- Birthday prayer section with Tamil blessing tags.

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
