# Trip Collection Dashboard

A responsive one-page website for managing group trip collections. It includes a traveler payment entry form, live dashboard totals, estimated budget view, collection records, payment mode reports, and trip readiness checklist.

## Features

- Add trip collection entries with traveler name, amount, payment mode, date, status, and notes.
- Live dashboard cards for total collected, estimated cost, balance needed, traveler count, and per-head estimate.
- Editable trip budget estimator for destination, people, transport, stay, food, activities, and buffer cost.
- Searchable and filterable collection table with remove actions.
- Progress ring, payment-mode split, and readiness checklist reports.
- Demo data saved in browser `localStorage`, with a reset button.
- Fully responsive layout for mobile, tablet, and desktop.

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
